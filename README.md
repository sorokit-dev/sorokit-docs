# Sorokit Developer Portal & Documentation (`sorobun-docs`)

The centralized knowledge hub, API reference guide, and interactive testing ground for the Sorobun SDK ecosystem.

Great documentation is the backbone of developer adoption. This repository houses the fast, Vite-powered documentation site and an active showcase dApp designed to onboard web developers into the Stellar Sorokit ecosystem in minutes.

### Key Capabilities
* **Step-by-Step Walkthroughs:** Clear installation paths, workspace configurations, and quick-start guides to help developers set up their first dApp from absolute scratch.
* **Interactive Code Sandboxes:** Live, browser-based playgrounds where developers can modify code snippets and see instantaneous changes using mock Sorokit contract calls.
* **End-to-End Example dApp:** A fully functional, production-ready reference application showcasing `@sorokit/core` and `@sorokit/ui` working in tandem to execute real testnet transactions.

*Step-by-step guides, clean sandboxes, and actual functional blueprints.*
