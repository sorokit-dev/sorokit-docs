# sorokit-docs

Documentation for the Sorokit SDK: [`@sorokit/core`](https://github.com/sorokit-dev/sorokit-core) (TypeScript engine and React hooks for Stellar Soroban) and [`@sorokit/ui`](https://github.com/sorokit-dev/sorokit-ui) (accessible Tailwind components for Stellar dApps).

> **Status: planned, not yet built.** This repository currently contains project files only. The documentation site has not been scaffolded and nothing is deployed. The roadmap below describes what we intend to build; it is tracked as issues.

## Roadmap

- **Getting started** — installation, workspace setup and a first dApp that connects a wallet and calls a contract
- **API reference** — every exported hook, adapter and component in `@sorokit/core` and `@sorokit/ui`
- **Guides** — wallet connection, contract calls and transaction state, transaction toasts, theming and dark mode
- **Interactive examples** — in-browser sandboxes using mock contract calls
- **Example dApp** — a reference app using `@sorokit/core` and `@sorokit/ui` together against Testnet

The site is planned as a [Vite](https://vitejs.dev)-based static site.

## Where things are today

Until the site exists, the READMEs are the source of truth:

- [`sorokit-core` README](https://github.com/sorokit-dev/sorokit-core#readme) — hooks, wallets and usage
- [`sorokit-ui` README](https://github.com/sorokit-dev/sorokit-ui#readme) — components, setup and known limitations
